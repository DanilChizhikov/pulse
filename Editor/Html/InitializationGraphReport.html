Pulse · Initialization Graph

    How to read this page

    Card

    One system the game starts up — saves, audio, ads, analytics, and so on.

    ⇥

    Column

    A startup step. Nothing in a column begins until every column to its left has finished.

    →

    Arrow A → B

    B waits for A. A has to be ready before B can start.

    Card colour

    How long that system took in this run: green is among the fastest, red is the slowest one here. It is a comparison inside this run, not a pass/fail mark.

    CRITICAL

    Critical

    The game waits for it before the first screen appears. CRITICAL (dep) means it was pulled into that wait because a critical system needs it.

    Red outline

    The system failed. Open the panel at the top of the page to read the error.

    Orange outline

    The system was cancelled before it could finish.

    Grey card

    The system never started — usually because the run stopped earlier.

    Indirect links

    Arrows that another, longer path already implies. Hidden by default to keep the picture readable.

    ✥

    Moving around

    Drag to move, scroll to zoom, click a card to see only what it touches, press Fit or double-click to see everything.
